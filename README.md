# Website for HowToVoteInAustin.org and ComoVotarEnAustin.org

The website might be available [here](https://howtovoteinaustin.org).

In Texas, voting is done by county and Austin spans multiple counties.
This website helps people find their county and gives them the very
first few steps towards voting in very simple language.

This project was created by the Michael Nahas Campaign, for Michael
Nahas's run for Austin City Council in 2026.
